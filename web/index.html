Luma

Luma's public API cannot see calendars you follow, so this app reuses your luma.com browser session. The key stays on this server.

  1. Sign in at luma.com in this browser.
  2. Open DevTools (F12 or Cmd-Opt-I) → Application (Chrome) or Storage (Firefox/Safari) → Cookies → luma.com.
  3. Copy the value of luma.auth-session-key and paste it below.

Partiful

Partiful has no API, but it gives every account a personal calendar feed. On any Partiful event page click the calendar icon, choose Google Calendar, then Copy Link. Paste that link here. It covers the events you are invited to, going to, or hosting, per your Partiful calendar-sync preferences.
